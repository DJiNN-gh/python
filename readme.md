Estudo sobre a linguagem Python realizado durante a disciplina de Algoritmos e Lógica de Programação

# Disclaimer
Todo conteúdo aqui contido é de livre visualização e cópia, ficando à discrição dos consultantes o uso dos códigos deste repositório.

# Conteúdo:

#### biblioteca - pesquisa acerca das ferramentas da linguagem Python. Os tópicos abordados são descritos pelo nome de cada arquivo.

#### exercicios_huxley - resolução de exercicios da plataforma The Huxley.

#### projetos - programas desenvolvidos para resolução de problemas genéricos ou construção de estruturas.

#### python_pro - exercícios elaborados por mim e suas respectivas resoluções, como jornada de aprendizado da linguagem Python, baseados no livro Learning Python, do Mark Lutz.

#### scripts - algoritmos para execução em terminais, com a funcionalidade descrita pelo nome do arquivo.
